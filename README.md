# AI-Long-Text-Generation-Practice# AI Long Text Generation Practice


基于大语言模型的长文本生成实践项目。


## 项目介绍

本项目基于开源项目 chinese-novelist-skill 进行学习，
探索大语言模型在长文本创作场景中的应用流程。

通过设计故事背景、人物关系、剧情结构，
完成从创意设计到文本生成和内容整理的完整流程。


## 项目成果

完成作品：

《他必须活》

类型：

中篇小说


项目包含：

- 世界观设计
- 人物角色设计
- 剧情规划
- 多章节文本生成
- 内容整理优化


## 学习内容

通过本项目学习：

- Prompt 设计方法
- 长文本生成流程
- AI 辅助创作方法
- 大模型应用场景


## 实践流程

1. 确定故事主题

2. 设计人物和世界观

3. 制定故事章节结构

4. 使用 AI 工具辅助生成内容

5. 人工整理和优化文本
