# AI Long Text Generation Practice

基于大语言模型的内容生成实践项目。


## 项目介绍

本项目基于开源 AI 工具进行学习实践，探索大语言模型在长文本生成场景中的应用方式。

通过 AI 辅助完成故事设计、内容生成以及文本整理流程，了解 AI 工具在实际内容生产中的使用方法。


## 使用工具

- 大语言模型
- Prompt设计
- AI辅助创作工具
- GitHub
- Markdown


## 项目成果

完成中篇小说作品：

《他必须活》


项目过程包含：

- 故事主题设计
- 世界观构建
- 人物关系设计
- 章节规划
- AI辅助生成
- 内容整理优化


## 实践流程

1. 确定创作方向

2. 设计故事背景和人物关系

3. 调整提示词优化生成效果

4. 对生成内容进行筛选和修改

5. 整理形成完整作品


## 学习收获

通过项目学习：

- 了解大语言模型应用流程
- 理解 Prompt 对生成效果的影响
- 掌握 AI 辅助完成任务的方法
- 探索 AI 在内容生产中的应用场景
